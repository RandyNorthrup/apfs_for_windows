# APFS for Windows 0.1.0

Initial public beta release.

## Included

- Native APFS access through Windows Explorer.
- Automatic supported-device discovery and drive-letter assignment.
- Read, write, create, rename, move, and delete operations.
- File, directory, link, timestamp, attribute, security, xattr, and stream support.
- Automatic mount service with supervised workers.
- Persistent stacked `AP`/`FS` tray manager.
- Read-only/read-write, drive-letter, automount, and unmount controls.
- Install, repair, uninstall, and Test Signing helpers.

## Requirements

- Windows 11 x64 only.
- Administrator access for installation.
- Windows Test Signing enabled for the included test-signed filesystem driver.
- Secure Boot disabled when required by Windows Test Signing.

Read the [installation guide](https://github.com/RandyNorthrup/apfs_for_windows/blob/main/docs/INSTALLATION.md)
before installing.
